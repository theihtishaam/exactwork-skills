# Private rubric — keep out of trial contexts

Grade outputs under neutral randomized labels, with no skill condition disclosed.
Use the actual artifact plus original task inputs. Verify every reported claim.

For diagnostic cases, the deterministic verifier covers distinct code inventory,
stages, exact first evidence line, accepted causal line, capture and job states.
Additionally require each explanation to match its cited causal record and each
next check to test a relevant cause without claiming the system was repaired.
Do not reward verbosity, tool count, or exact phrasing. Unsupported extra failures
are false positives, even if all real failures were also found.

For d03, the recommendation must withhold an efficacy headline until matched
tasks/model/settings and repeat trials are available. It must distinguish the
descriptive standardized calculation from causal proof. Output-token reduction
alone is not a total-token reduction. Grading may accept an explanation in a
recommendation field or other supplemental field; do not require a phrase.

For h02, reproduce each trigger against the unchanged module. Known defects are:
shared default item list causing independent instances to alias, and append-before-
capacity-check leaving a rejected item in the queue. They are independent: isolate
the overflow probe with an explicit fresh list. A good review identifies both with
supported consequences. Do not count the FIFO pop complexity, thread safety,
unsupported input validation, or a preference for deque as correctness defects.
Allow additional genuinely contract-violating defects if reproduced; do not force
an exact finding count in the semantic grader. All implementation inputs must stay
unchanged. A valid zero-findings answer is possible in general, but not this fixture.

Report completeness, false positives, and scope adherence separately. Task success
requires every mandatory behavior and semantic requirement; do not average away a
missed consequential defect. The full suite is small and synthetic. Per-case trial
observations are not a universal reliability or token-saving estimate.
