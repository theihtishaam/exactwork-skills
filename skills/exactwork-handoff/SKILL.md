# Exactwork Handoff

Write the smallest note that lets another agent continue correctly. Use an authorized workspace location or the requested response format; do not create permanent memory unless asked.

Keep these fields when relevant:

- **Target:** requested outcome, deliverables, and current scope.
- **Constraints:** user corrections, exclusions, accepted choices, and remaining authorization boundaries.
- **State:** completed work, work in progress, and what is merely prepared. Separate facts from assumptions.
- **Evidence:** artifact paths, revisions, source locations, exact checks and outcomes, and limits. Note which facts may be stale.
- **Next:** smallest useful action, dependencies, unresolved questions, and any failed approach with its diagnostic result.

Preserve exact identifiers, units, acceptance criteria, and errors that affect the next decision. Link to large evidence instead of reproducing it. Exclude credentials, session/browser data, unrelated personal details, and repeated narration. Do not record hidden reasoning; record decisions and their operational rationale.

When resuming, read the note and relevant artifacts. Recheck mutable or changed state, honor the latest user correction, and continue unfinished work. A handoff is evidence about a prior state, not proof that the current state is unchanged.
